# 1. סקירה כללית

## 1.1 מטרת המערכת

מערכת "מסך חכם יהודי" היא אפליקציית Android המיועדת לרוץ על טאבלט קבוע בסלון הבית. המערכת מספקת גישה מבוקרת ומסוננת לתכנים יהודיים ולכלים שימושיים למשפחה, תוך חסימה מוחלטת של תכנים לא רצויים וגלישה חופשית.

## 1.2 עקרונות מנחים

| עיקרון | תיאור |
|--------|-------|
| **סינון מוחלט** | אין גישה לאינטרנט הפתוח - רק לתכנים מאושרים |
| **פשטות** | ממשק נקי ופשוט לשימוש לכל בני המשפחה |
| **יהדות** | התאמה מלאה ללוח העברי, זמני היום והמסורת |
| **אמינות** | פעולה יציבה 24/7 כמסך קבוע בבית |
| **שליטה הורית** | הגדרות ושינויים רק עם קוד PIN |

## 1.3 שם המוצר (הצעות)

- בית יהודי
- מסך הבית
- לוח הבית
- שולחן יהודי
- HaBoard

# 2. קהל יעד

## 2.1 משתמשים עיקריים

### משפחות דתיות/חרדיות
- רוצים מסך בבית ללא חשש מתכנים לא ראויים
- צריכים גישה מהירה לזמני היום
- רוצים אלפון משפחתי נגיש

### משפחות מסורתיות
- רוצים חיבור ללוח העברי
- מעוניינים בתכני יהדות נגישים
- צריכים מתכונים כשרים

## 2.2 פרופיל גילאים

| קבוצה | גיל | צרכים עיקריים |
|-------|-----|---------------|
| ילדים | 4-12 | ברכות, שירים, ממשק פשוט |
| נוער | 12-18 | מוזיקה, לוח שנה, מתכונים |
| מבוגרים | 18+ | אלפון, לוח שנה, זמנים, הגדרות |
| קשישים | 65+ | ממשק גדול וברור, אלפון |

```kotlin
class RecipeWebView(context: Context) : WebView(context) {

    private val allowedDomains = listOf(
        "niki-b.co.il",
        "foodish.co.il",
        "10dakot.co.il"
    )

    init {
        settings.apply {
            javaScriptEnabled = true
            domStorageEnabled = true
            allowFileAccess = false
            allowContentAccess = false
        }

        webViewClient = object : WebViewClient() {
            override fun shouldOverrideUrlLoading(
                view: WebView,
                request: WebResourceRequest
            ): Boolean {
                val host = request.url.host ?: return true
                return !allowedDomains.any { host.endsWith(it) }
            }
        }
    }
}
```

```kotlin
class AdBlockWebViewClient : WebViewClient() {

    private val adPatterns = listOf(
        "doubleclick.net",
        "googlesyndication.com",
        "googleadservices.com",
        "facebook.com/tr",
        "analytics",
        "taboola",
        "outbrain"
    )

    override fun shouldInterceptRequest(
        view: WebView,
        request: WebResourceRequest
    ): WebResourceResponse? {
        val url = request.url.toString()
        if (adPatterns.any { url.contains(it) }) {
```

# 8. אינטגרציות חיצוניות

## 8.1 Google APIs

### Google Calendar API
- **Scope:** `https://www.googleapis.com/auth/calendar.readonly`
- **שימוש:** קריאת אירועים מהיומן
- **סנכרון:** כל 15 דקות + עדכון ידני

### Google People API (Contacts)
- **Scope:** `https://www.googleapis.com/auth/contacts.readonly`
- **שימוש:** קריאת אנשי קשר
- **סנכרון:** כל שעה + עדכון ידני

### Google Photos API
- **Scope:** `https://www.googleapis.com/auth/photoslibrary.readonly`
- **שימוש:** קריאת תמונות ואלבומים לשומר מסך ולגלריה
- **סנכרון:** כל שעה + עדכון ידני
- **מטמון:** תמונות נשמרות מקומית להצגה מהירה

### OAuth 2.0 Flow
```
┌──────────┐     ┌──────────┐     ┌──────────┐
│   App    │────>│  Google  │────>│   User   │
│          │     │  OAuth   │     │  Consent │
└──────────┘     └──────────┘     └──────────┘
      │                                 │
      │         Access Token           │
      │<───────────────────────────────│
```

## 8.2 Hebcal API

- **Endpoint:** `https://www.hebcal.com/hebcal`
- **שימוש:** חגים, פרשות, תאריכים עבריים
- **מטמון:** 24 שעות

### דוגמת קריאה
```
GET /hebcal?v=1&cfg=json&year=now&month=now
    &ss=on&mf=on&c=on&geo=geoname&geonameid=281184
```

- **שימוש:** חישוב זמני היום offline
- **תלות:**

```gradle
implementation 'com.kosherjava:zmanim:2.5.0'
```
